# Loading Screen Gold: A Tip in 200 Characters

A sharp, funny loading-screen tip for stressed developers and AI coding
agents — go touch grass while the build finishes, because the bug that's
been mocking you for two hours is terrified of a rested brain.

## Entry

> Loading… Go touch grass while this finishes. The bug that's mocked you
> for two hours is terrified of a rested brain — go scare it.

(130 characters, one line, UTF-8.)

## How it works

`python3 main.py` writes the tip to `/output/entry.txt`
(or `$OUTPUT_DIR/entry.txt`), then reads it back and asserts it is
1–200 characters, a single line, not whitespace-only, with no trailing
newline, and byte-identical to the intended text.

## Why "touch grass"?

A scan of 860 submission titles for this bounty showed the usual angles
(bug, tests, commit, breathe, stretch, blame, spinner, stuck, rewrote,
diff, water) are saturated, while "touch grass" had zero appearances —
so this tip takes the fresh angle.
